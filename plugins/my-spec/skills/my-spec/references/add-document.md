# my-spec-add

只读取用户指定的文档和当前 `openspec/specs/`；不得扩展为全仓库扫描。

1. 获取共享运行锁，记录主规格与指定文档指纹，状态设为 `ANALYZING`。
2. 从指定文档提取可观察、可验证的行为，按主规格分类为新增、修改、删除、明确改名、确定重复或冲突。
3. 标题和正文相同的内容不产生变更。删除、来源冲突和低可信候选进入 `WAITING_DECISION`。
4. 一次只展示一条：候选全文、来源证据、不能自动决定的原因、推荐答案；只接受“接受、忽略、修改后接受、暂缓”之一并保存游标。暂缓不进入预览。
5. 没有未决项后生成 Delta（增量规格），用 `spec_ops.py` 校验并生成完整预览。
6. 校验预览，用 `diff` 展示完整差异，状态设为 `READY_TO_APPLY`，等待最终确认。
7. 确认后重查主规格指纹并原子应用；最终校验成功才清理工作区。失败恢复原规格并保留诊断现场。

禁止一次展示全部冲突或批量采用建议。相同输入和决定应产生相同预览；已满足的内容不应再次生成 Delta（增量规格）。
