# 03 — 完成 `/spec-review` 内部审查

**What to build:** 用户运行 `/spec-review` 后，只针对主规格库内部的确定重复、语义冲突、明确过期和格式问题得到审查结果，并通过统一的逐条决策、预览、差异和确认流程安全更新规格。

**Blocked by:** 02 — 补齐安全决策与失败恢复。

**Status:** ready-for-agent

- [ ] 审查范围严格限制为主规格库，不扫描仓库文档、测试或代码。
- [ ] 标题和正文均相同的确定重复可以自动合并。
- [ ] 标题不同但语义等价、标题相同但正文不同、Scenario（场景）部分重叠均作为冲突逐条确认。
- [ ] 只有规格内部存在明确废止、停止支持、替代或版本失效证据时才生成过期候选。
- [ ] 所有删除逐条确认；无内部证据的内容不会被判定为过期。
- [ ] 只自动修复不改变语义的格式问题，其他格式缺失作为冲突处理。
- [ ] 端到端回归从 `/spec-review` 入口证明范围隔离、自动合并、逐条决策和最终应用。
