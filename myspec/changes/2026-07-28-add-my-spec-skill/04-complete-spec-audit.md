# 04 — 完成 `/spec-audit` 全仓库审计与初始化

**What to build:** 用户运行 `/spec-audit` 后，Skill（技能）能够读取 Git（版本管理）可见的仓库内容，对照主规格发现缺失、不准确或明确过期的行为要求；规格库不存在时，同一入口按空规格库完成初始化。

**Blocked by:** 02 — 补齐安全决策与失败恢复。

**Status:** ready-for-agent

- [ ] 扫描范围包含已跟踪及未忽略的新文件，并排除主规格、临时工作区、二进制内容及已忽略产物。
- [ ] 只提取用户或外部系统可观察、可验证的行为，不把内部实现细节写入规格。
- [ ] 主规格、需求文档、端到端测试、代码及辅助材料按约定顺序展示证据，但不会自动互相覆盖。
- [ ] 来源冲突和低可信候选逐条询问，并提供证据、原因和推荐答案。
- [ ] 主规格不存在时按空库生成初始 Delta（增量规格），不需要独立初始化命令。
- [ ] 已有规格库时生成相对于当前主规格的审计结果，并复用完整预览、差异、最终确认和回滚流程。
- [ ] 端到端回归分别覆盖空库初始化和已有规格库全仓库审计。
