# 05 — 安装并验证完整 my-spec Skill（技能）

**What to build:** 用户可以从仓库源码安装 my-spec Skill（技能）供共享 Agent（代理）使用，并让 Claude（代码代理）通过目录链接使用同一安装副本；安装后可以从真实入口完成三个命令的主流程。

**Blocked by:** 03 — 完成 `/spec-review` 内部审查；04 — 完成 `/spec-audit` 全仓库审计与初始化。

**Status:** ready-for-agent

- [ ] 安装能力将仓库 Skill（技能）源码同步为独立的共享安装副本，而不是让共享目录直接链接仓库源码。
- [ ] Claude（代码代理）使用指向共享安装副本的目录链接，不维护第二份源码副本。
- [ ] 重复安装能够更新共享安装副本并保持正确的 Claude（代码代理）目录链接。
- [ ] 目标位置存在来源不明的目录或非预期链接时停止，不覆盖、不删除。
- [ ] 插件清单和 Skill（技能）入口可被目标 Agent（代理）正确发现。
- [ ] 完整集成回归从安装形态依次覆盖 `/spec-add`、`/spec-review` 和 `/spec-audit` 的主要业务流程。
