# 02: 仅复用完整成功的测试安装缓存

**What to build:** 测试工具打包或安装准备失败后，后续调用重新准备并报告真实结果；只有必要文件完整的成功安装才允许复用，同时保留现有成功缓存的性能收益。

**Blocked by:** 无，可独立开始；推荐在票据 01 后串行实施，但它不是本票的功能前置依赖。

**Status:** ready-for-agent

- [ ] 打包和安装在局部候选对象中完成，成功前不登记共享安装缓存。
- [ ] 登记前确认压缩包、命令入口和已安装工具包清单存在。
- [ ] 打包失败、安装失败或必要文件缺失不留下可复用缓存，不以忽略错误代替失败报告。
- [ ] 使用现有进程内测试接缝覆盖首次失败后的再次准备成功及成功缓存复用，不新增重复真实打包安装测试。
- [ ] 保留已有真实打包、隔离安装与公开命令入口覆盖；红灯、绿灯与最终冒烟从 Build and Verify（构建与验证）真实公开入口执行。
- [ ] 不改变工具产品行为、打包路径保护、验证配置和预算，不修改正式主规格。
