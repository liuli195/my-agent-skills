# 01 — 更新子代理策略与具名配置

**What to build:** 四个子代理角色的实际配置与技能契约统一到用户确认的 GPT-6 模型和思考强度；主代理可在同一工作区对互不冲突的票据安排子代理并行，冲突任务与共享 Git 操作保持串行。

**Blocked by:** None（无，可立即开始）。

**Status:** ready-for-agent

- [ ] Explorer / Implementer 使用 `gpt-6-luna`，思考强度分别为 `low` / `max`。
- [ ] Reviewer / Architect 使用 `gpt-6-sol`，思考强度均为 `high`。
- [ ] 技能、具名配置和检查一致；职责与读写边界不变。
- [ ] 同一工作区仅对主代理判定独立且互不冲突的票据允许可写子代理并行；共享 Git 操作串行。
- [ ] 从现有技能加载入口及具名配置验证上述可观察结果。
