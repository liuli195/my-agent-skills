# 02 — 更新开发流程门禁一与并行审查选择

**What to build:** 开发者在原工作区的门禁一获得 AI 推荐，并明确确认分支、实施和审查三组选择；流程按已确认选择开发和审查独立票据。

**Blocked by:** 01 — 更新子代理策略与具名配置。

**Status:** ready-for-agent

- [ ] 门禁一展示当前工作区及准确的现有或拟新建功能分支名称，不提供新建工作区；分支动作在授权后执行。
- [ ] AI 给出一套具体推荐和简短理由；用户可接受整套推荐或逐项选择，推荐自身不构成授权。
- [ ] 分支、串行/并行与主/子代理开发、每票/最终审查三组均明确确认才通过门禁。
- [ ] 并行仅由子代理对主代理确认独立的票据执行；依赖或范围冲突、共享 Git 操作串行，主代理核验结果。
- [ ] 审查按选择的时机由子代理 Reviewer（审查者）执行；入口不可用时停留审查步骤。
- [ ] 真实入口测试、正式验证、门禁二及交付规则保持有效，并经现有技能加载入口验证。
