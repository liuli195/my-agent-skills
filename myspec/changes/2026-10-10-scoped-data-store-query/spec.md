# 显式范围的数据存储查询与项目接入

状态：门禁一已确认，实施与验证中；临时溢写例外已补充确认

## Problem Statement

公共通用查询先发现并注册整个数据根目录的全部逻辑表。魔兽结果查询因此会打开不相关的历史批次，在查询启动阶段带来大量准备开销和内存风险；无关损坏表还会阻塞目标查询。项目共用入口虽然已有连接命令，统一初始化没有接入该命令，新工作树缺少可用入口。

## Solution

调用者必须明确声明本次通用查询的逻辑表范围，公共技能只枚举、登记这些表，并仅把对应业务分片加入显式文件许可名单；引擎现有临时溢写目录保留为明确例外。未迁移调用及越范围访问明确失败；查询不再推测范围、自动补表或回退到整个数据中心。统一初始化只为清单明确声明数据存储能力的项目复用既有连接与检查入口，保持正式发布来源与现有准备流程。

## User Stories

1. 作为调用者，我希望指定所需逻辑表，让无关历史批次不参与查询准备。
2. 作为调用者，我希望缺少、空或无效范围在目录操作前失败，便于发现尚未迁移的调用。
3. 作为调用者，我希望声明多个表后继续执行参数化关联、嵌套字段和分批消费。
4. 作为调用者，我希望未声明业务表及其文件被原生查询引擎拒绝，而非扩大读取范围；临时溢写目录保留为明确例外。
5. 作为调用者，我希望目标不存在或没有已完成分片时，仍能通过系统表检查不存在；普通目标查询返回正常缺表错误。
6. 作为调用者，我希望无关损坏表、非法目录和历史数据保持不被访问，目标损坏仍明确失败。
7. 作为已有使用者，我希望单键、多键读取的字段筛选、值类型和缺失、损坏、暂时不可用的错误分类保留。
8. 作为项目维护者，我希望消费者加载技能时一次检查查询能力，不在每次查询时检查安装状态，也不静默使用旧能力。
9. 作为项目维护者，我希望统一初始化为声明了数据存储需求的项目连接并检查共用入口，新工作树可重建接入关系。
10. 作为其他项目使用者，我希望尚未发布的可选技能或未声明的数据存储能力不强制安装，也不改全局技能来源。

## Implementation Decisions

- Module（模块）沿用数据存储技能及统一云端初始化；Interface（接口）为原有公开编程调用、安装形态命令行及统一初始化命令；Seam（接缝）不增加。
- 通用查询采用必需的非空逻辑表列表关键字参数，保留原参数化查询参数。逻辑名称沿用大小写规则，重复声明不重复读取。
- 漏传、空值、空列表或非法名称先失败；查询引擎原生声明类型检查在枚举目标目录前完成。只接受单条只读查询，不增加自写查询解析器。
- 只枚举声明的目标表。不存在和空目标不登记逻辑视图；不读取其他表以猜测结构。不把错误转换成扩大范围的重试。
- 原生显式文件访问白名单仅包含本次选定业务分片，关闭外部访问与自动扩展并锁定配置；逻辑目录和分片不得通过链接重定向到其他表或数据根之外。已知键读取使用相同的文件范围原则。保留引擎既有临时溢写目录及内存策略，临时目录是明确例外，不承诺阻止人工查询读取其中的文件，正常业务不得以其为数据源；不新增目录管理、清扫或查询解析器。
- 单键、多键的字段和筛选接口保持，已有有限调优决策机制不扩建，不增加常驻连接或新缓存。
- 能力版本优先使用现有发布机制；若发布元数据不能标识尚未发布的接口，使用最小公共能力版本常量，消费者只在加载时检查。不将开发版本设置为全局安装。
- 初始化清单按项目显式声明需要连接的技能。已发布来源可用时复用连接与检查命令；可选技能尚未发布时保持待发布状态，已有冲突或错误来源保留并明确失败。
- 现有正式规格要求通用查询登记并检查全部逻辑表，与本次已批准的不兼容接口变更冲突。门禁二前只准备正式规格候选，保留正式规格原文件。

## Testing Decisions

- 最高公开入口沿用独立安装形态的数据存储命令行，公开编程调用辅助核对必需参数、错误类型及游标；初始化使用统一命令入口与真实连接脚本。
- 使用固定 DuckDB（分析查询引擎）1.5.6、极小合成样本；不重放生产全库或历史成绩。
- 红灯到绿灯覆盖无关坏表隔离、必需范围早失败、多表关联、未声明业务表及文件拒绝（保留临时溢写目录例外）、目标缺失和空表系统查询语义、目录或分片链接越范围拒绝。
- 原有点读与批量字段筛选、同键替换后新数据、多表与嵌套值和类型检查保留。初始化覆盖声明项目成功接入、重跑复用、可选技能缺失、无声明项目及冲突保留。
- 正式验证复用 Build and Verify（构建与验证）快速入口，固定基线后必须选择非空检查并通过；改动后执行相同入口的安装形态冒烟。
- 两仓库按冻结的公共接口并行实施，公共技能票据内部串行红绿；全部完成后由已有独立 Astra（模型）审查者检查实际差异。角色与模型实际配置如实记录，不声称使用未执行的配置。

## Out of Scope

正式发布、合并、主干直推、本机部署；修改生产数据及历史成绩；全历史重新验收；数据库、索引、后台服务、新缓存框架；任意查询绝对文件安全沙箱、溢写目录管理或关闭溢写；专用静态检查器、自写查询解析器、资源调度或操作系统管理；全库查询回退；重建全局安装来源。
