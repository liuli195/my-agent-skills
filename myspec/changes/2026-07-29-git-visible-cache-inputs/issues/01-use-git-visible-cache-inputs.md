# 01 — 让目录型缓存输入遵循 Git 可见文件

**What to build:** 让 Build and Verify（构建与验证）在 Git（版本管理）仓库中仅使用已跟踪文件和未被忽略的未跟踪文件计算目录型缓存输入，同时保留显式单文件语义和非 Git 场景的现有回退行为。完成后，依赖目录和构建产物只要已被仓库忽略，就不会拖慢缓存键计算。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 目录型缓存输入包含已跟踪文件。
- [ ] 目录型缓存输入包含未跟踪且未被忽略的文件。
- [ ] 目录型缓存输入排除被 Git 忽略的未跟踪文件。
- [ ] 显式指定的被忽略单文件仍参与缓存键计算。
- [ ] Git 不可用、命令失败或目标不是 Git 仓库时回退现有目录遍历。
- [ ] 文件名通过无歧义的空字符分隔结果处理。
- [ ] 不新增固定排除目录、配置字段、文件清单缓存或调度改动。
- [ ] 规范实现与仓库运行时快照保持同步。
- [ ] 现有最高层运行器测试覆盖完整行为，且完整验证通过。
