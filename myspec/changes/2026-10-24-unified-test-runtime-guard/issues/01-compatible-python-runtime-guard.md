# 01: 兼容迁移与 Python 保护闭环

**What to build:** 用户升级插件后，旧项目仍按原配置验证且明确显示未保护；新初始化或显式迁移的 Python（编程语言）项目，从同一公开总命令进入受保护的普通测试与按场景显式登记的真实集成／冒烟检查，保留两层并行、真实失败、报告和缓存语义。

**Blocked by:** None (can start immediately)（无前置票；仍须门禁一批准）。

**Status:** ready-for-agent

- [ ] 使用配置版本与项目显式真实检查 ID（标识）清单区分旧、新模式；纯内存项目允许空清单，有真实场景时按需登记一项或多项，各项必须对应实际存在的验证检查且不得重复，不增逐项复杂权限矩阵。未登记普通测试默认保护；旧配置不自动改写、不自动启用限制、不阻断旧验证，也不冒充新规则通过。新初始化默认新规则。
- [ ] 显式迁移复用初始化覆盖与备份能力；新规则配置不完整、缺少清单、标识不存在／重复等在检查启动前明确失败。恢复备份必须为显式动作并标明旧模式未保护，不静默降级。
- [ ] 旧项目任意字符串、列表、组合命令及现有包管理／环境工具链保持原行为；快速、完整、差异、拉取请求过滤、通过／失败／跳过及诊断语义不变。当前尚未完成的语言保护不得伪报成功。
- [ ] 代表契约覆盖视窗系统虚拟环境路径、`set …&&`（环境赋值后成功续行）、引号、方括号测试定位、忽略路径与名称筛选；同时覆盖 pytest（测试框架）收集 unittest（标准测试框架）和直接 Python 脚本。保留原参数、环境、退出码及短路，不以猜测任意封装命令安全替代保护；新模式未登记检查中的未识别／未覆盖测试段明确报错，不自动降级或把整组未知命令登记为真实检查。
- [ ] `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`（关闭测试插件自动加载）时仍显式加载守卫；保留 Quant 的 `NUMBA_DISABLE_JIT`（禁即时编译）逐项差异，JIT（即时编译）专项不得统一禁用。保留工作树专项 `PYTEST_ADDOPTS=-n 4`（四工作进程）及 `-p xdist.plugin`（显式加载并行插件）；不把外层允许并行误当内层已并行。
- [ ] 同一公开验证入口中的 Python 普通测试，从项目导入前开始保护控制进程与全部工作进程；导入、准备、正文、清理、辅助函数及线程中的业务外部进程、联网、真实文件变更被拒绝，必要读取和内存逻辑可运行。
- [ ] 框架仅可通过固定受限通道启动既定工作单元，不能按整个控制进程或调用栈放行；新建与重启工作进程在项目代码加载前受保护，业务不能调用通用暂停／豁免接口。
- [ ] 违规独立记账；吞异常、业务返回成功或工作进程重启仍失败。守卫未加载、工作进程失联／崩溃、保护结果缺失或不完整均失败。
- [ ] 真实证明外层检查并行与 pytest-xdist（Python 并行测试插件）内层并行保留，并保护控制端项目回调；多项真实检查与普通测试共用既有调度、每项超时和项目总预算，真实入口增多不额外分配项目预算，不通过串行化或缩小覆盖规避限制。
- [ ] 复用既有运行控制、取消、单项超时、总截止及拥有进程树回收，不影响无关进程；违规、超时、取消、未完成及诊断不得写正式成功缓存。
- [ ] 缓存与保护证据区分旧、新策略、适配器及每项检查的普通／真实角色和清单策略身份；同一检查进出真实清单后不混用旧证据，原无守卫的真实成功不得供普通模式复用，新模式不得命中旧模式成功结果。普通性能报告写入失败保留警告语义，但必要保护证据缺失不得通过。
- [ ] 使用现有可注入执行器与受控时钟完成内存分支红灯到绿灯；以最少代表验收空清单、一项／多项、缺失／不存在／重复标识、未登记默认保护与真实检查并行不串权；少量真实场景从官方打包、隔离安装后的裸命令证明初始化／迁移、违规及合法两层并行，不新增重复重型预检。
- [ ] 仅验收插件及隔离示例项目的完整可观察闭环；按规格三仓盘点选取最少代表样例，不冒称另两仓整仓通过，不提前迁移任何消费仓库，不改变全局安装或开发源码绑定。记录 Windows（视窗系统）与 Linux（开源操作系统）待补证据，不把单平台结果当跨平台通过。

公开测试接缝：已安装的同一初始化／验证命令；逻辑分支复用现有主函数与可注入执行器。失败恢复接缝：显式备份恢复、工作进程重新受保护、取消回收和无成功缓存。实现完成后先独立审查并修复，再进入02票。
