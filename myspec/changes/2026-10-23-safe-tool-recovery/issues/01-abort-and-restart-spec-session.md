## Acceptance criteria（验收）

- [ ] 裸 myspec state-abort（会话中止）核验外部无活动会话确认、精确锁／状态／目标工作树身份；不按时间或命令进程已退出推定安全，不提供忽略身份的强制解锁。
- [ ] 保留 Delta、决定、预览及失败记录，先归档到工作根内部唯一 aborted（已中止）目录，再释放本次锁；归档失败保持原锁与原材料，重复操作不误伤新会话。
- [ ] 支持现有2.3.0仅含 add 换行的旧锁：精确旧状态／路径匹配、当前正式规格仍等于保存的原基线、无备份／部分应用现场，并取得外部无活动确认；不要求不存在的新字段，不补写历史身份。输入变化的失败预览可归档，但证据不足仍拒绝。

- [ ] state-init（会话初始化）发现已有 current（当前会话）内容不得静默删除；初始化失败仅撤回本次新建且仍归本次的锁。
- [ ] 新会话显式导入保留 Delta，不继承旧身份、决定、最终确认或就绪状态；重新分析、逐项决定、校验、展示完整预览，仍经既有最终确认才可正式应用。
- [ ] 从真实公开CLI（命令行）做失败／恢复红绿验证，覆盖归档失败、跨工作树、旧格式充分／不足证据、部分应用故障、初始化保护及导入后重走门禁；接入既有统一验证，不新增运行器。
- [ ] 受控打包及隔离安装形态冒烟通过，小规模记录归档／重建成本；不改全局安装、不删除原任务锁或应用原正式规格来凑测试通过。
