# 02: 一次读取多个目标键并直接选择字段

**What to build:** 保留当前文件存储，让技能使用者通过独立安装形态的读取入口，一次连接读取明确指定的多个记录键，既能读取完整报告，也能直接读取指定顶层字段；旧单键读取继续可用。随后与原生数据库按一致条件比较真实十二份报告。

**Blocked by:** 01：安装形态按逻辑键读取已保存记录（代码已在当前分支，补充需求仍须通过当前门禁一）。

**Status:** ready-for-agent

- [ ] 安装形态命令行与公开 Python 入口支持多键完整/指定字段，保留旧单键调用和游标分批消费。
- [ ] 只读取指定目标；重复键不造成重复结果，不扫描无关历史文件；字段名安全校验，空输入和未知字段明确报错。
