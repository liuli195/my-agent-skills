# 01: 安装形态按逻辑键读取已保存记录

**What to build:** 调用者使用写入时的逻辑表和记录键，通过安装后的数据存储技能只读取目标记录组，保留类型、替换和失败含义。

**Blocked by:** None (can start immediately)。仍须先通过门禁一。

**Status:** ready-for-agent

- [ ] 点读与写入使用相同逻辑键规则，不暴露物理路径或枚举全部历史。
- [ ] 目标嵌套记录可分批消费，同键替换后新调用得到最新完整记录；原通用查询不变。
- [ ] 无关损坏分片不影响目标点读；缺失、确定损坏与存储执行故障可被调用者区别处理。
- [ ] 正常和异常路径关闭资源，复用现有路径/类型校验，不引入新后台能力。
- [ ] 用少量公开入口回归检查及独立安装形态冒烟验证；统一构建验证不扩大为大型性能测试。

## Comments

完成后由消费仓库接入并作真实数据验收；暂不安装覆盖用户全局技能或自动发布。
