# 03: 通用查询减少准备开销并自动选择读取配置

**What to build:** 技能使用者仍按完整逻辑表进行只读查询，无需调优参数；小规模复杂读取自动减少工作线程，其他读取使用引擎默认；减少重复准备开销，只缓存有限数量的配置选择，始终读取当次数据。

**Blocked by:** 02：一次读取多个目标键并直接选择字段（共用读取准备与类型判定，串行完成）。

**Status:** ready-for-agent

- [ ] 独立技能运行形态支持原有查询；全部表检查、参数、多表、嵌套、异构字段、特殊名称及只读限制保持。
- [ ] 对可靠识别的小规模复杂读取使用单线程，其余及未知计划保持引擎实际默认；不绑定业务表、字段、文件名，不增加调用者调优参数。
- [ ] 最多128条配置选择，不缓存结果或连接；同键覆盖、新文件或删除文件不复用过期判定，每次读取当前数据。
- [ ] 保留通用查询遇无关损坏表失败、逻辑键读取只检查目标、错误分类和资源关闭；不改变写入。
- [ ] 原有十三种读取及新批量入口，至少三轮公平实测并核对值与类型，首次和重复调用分别记录；回归与统一固定基线验证通过。
- [ ] 代码及测量方式由独立审查者统一审查；阻塞问题修复后复验，不提前修改正式规格或发布。
