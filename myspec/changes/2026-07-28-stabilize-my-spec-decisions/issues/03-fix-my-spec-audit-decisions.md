# 03 — 修复 my-spec-audit 的逐项审计

**What to build:** 用户运行 my-spec-audit 时，仓库审计产生的完整待决定清单在首次询问前固定，后续决定不会触发新的仓库扫描或改变同一次审计的候选集合。

**Blocked by:** 01 — 建立可恢复的待决定状态闭环。

**Status:** ready-for-agent

- [ ] audit 继续使用 Git（版本管理）可见范围并保留现有排除规则。
- [ ] 来源冲突、删除和低可信候选在首次展示前完整保存。
- [ ] 高可信确定项继续自动进入 Delta（增量规格），不混入待决定清单。
- [ ] 决定阶段只使用保存状态，主规格或审计输入指纹变化时停止。
- [ ] Skill（技能）契约测试覆盖固定候选集合和禁止重新扫描行为。
