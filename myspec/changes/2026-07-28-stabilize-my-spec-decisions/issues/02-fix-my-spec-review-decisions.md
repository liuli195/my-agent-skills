# 02 — 修复 my-spec-review 的逐项审查

**What to build:** 用户运行 my-spec-review 时，首次内部审查产生的完整待决定清单被固定保存，后续每次只展示清单中的当前项，不会通过重新扫描改变总数或顺序。

**Blocked by:** 01 — 建立可恢复的待决定状态闭环。

**Status:** ready-for-agent

- [ ] review 只读取主规格库，保持现有范围边界。
- [ ] 首次展示前通过共享状态命令保存全部冲突、删除、低可信及语义格式候选。
- [ ] `WAITING_DECISION` 期间只读取保存状态，明确禁止重新扫描获取下一项。
- [ ] 完全相同的重复继续自动合并，所有删除继续逐条确认。
- [ ] Skill（技能）契约测试覆盖稳定总数、顺序和新进程继续行为。
