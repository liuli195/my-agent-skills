# 01 强制加载需求阶段指定 Skill（技能）

- 状态：ready-for-agent
- 关联问题：#244
- 前置票据：无

## 用户结果

单会话需求讨论只会在当前会话真实加载 `grill-with-docs`（带文档拷问）和 `domain-modeling`（领域建模）后开始；普通 `grilling`（拷问）不能替代指定入口，指定 Skill 不可用时流程停止。

## 实现范围

- 在需求讨论入口增加独立、醒目的 MUST（强制）块。
- MUST 块明确要求当前会话真实加载两个指定 Skill、禁止替代、加载失败时停止，并在生成规格和票据前核对工具记录。
- 保留普通执行规则在实际步骤中的位置，不把无关规则扩大为 MUST 块。
- 不新增状态文件、布尔标记或由模型自行判断的伪运行时门禁。
- 扩展现有 Pi Package（Pi 包）契约检查，并通过真实 Pi 新进程观察需求入口。

## 验收标准

- [ ] 需求讨论入口包含独立 MUST（强制）块。
- [ ] MUST 块同时要求 `grill-with-docs`（带文档拷问）和 `domain-modeling`（领域建模）。
- [ ] MUST 块明确禁止普通 `grilling`（拷问）替代指定入口。
- [ ] 任一指定 Skill 缺失、不可读或加载失败时，流程明确停止并报告。
- [ ] 调用 `to-spec`（生成规格）和 `to-tickets`（拆分票据）前核对本轮工具加载记录。
- [ ] 真实 Pi 新进程从本地包进入需求阶段时使用正确入口。
- [ ] Build and Verify（构建与验证）对应检查通过。
