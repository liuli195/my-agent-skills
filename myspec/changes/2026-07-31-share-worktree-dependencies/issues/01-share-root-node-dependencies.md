# 01 共享根目录 Node.js 依赖

- 状态：ready-for-agent
- 前置票据：无
- 对应 GitHub Issue（问题）：#230

## 用户结果

开发者只需在主仓库安装一次 Node.js（运行时）依赖；随后初始化任意 `.worktrees/` 工作树，即可通过目录链接直接运行完整构建，不再重复下载或复制约 409 MB 的依赖。

## 实现范围

- 将仓库根目录设为 npm workspace（npm 工作区）。
- 将 `pi-tool-display` 的锁文件和开发依赖安装提升到仓库根目录，同时保留插件包边界。
- 更新 `scripts/setup-worktree.ps1`：
  - 主仓库负责安装根目录依赖；
  - 工作树只创建根级 `node_modules` 目录链接；
  - 共享依赖缺失或依赖清单不一致时明确停止并给出恢复位置。
- 更新现有用户入口测试和必要说明。

## 验收标准

- [ ] 新检出的主仓库可通过 `scripts/setup-worktree.ps1` 准备 Python（脚本语言）开发环境和根目录 Node.js（运行时）依赖。
- [ ] 新工作树运行同一脚本后，根级 `node_modules` 是指向主仓库根目录依赖的目录链接。
- [ ] 工作树不会执行 `npm ci`，也不会创建独立大型依赖实体。
- [ ] 共享依赖不存在时，脚本停止并提示在主仓库根目录初始化。
- [ ] 依赖清单与主仓库不一致时，脚本停止且不修改共享依赖。
- [ ] `plugins/pi-tool-display` 通过根目录共享依赖完成构建和测试。
- [ ] Build and Verify（构建与验证）真实主流程通过。
