# 02 — 沉淀动态扫描配置与受控探测规则

- 状态：ready-for-agent
- 关联问题：#255
- 前置票据：无

## 用户结果

构建与验证初始化、审查能够用通用规则识别动态扫描命令的实际输入范围；静态证据不足时，用户可确认必要候选命令的受控分组探测，并在可见副作用出现时安全停止。

## 实现范围

- 在初始化和审查的共享参考规则中说明动态扫描范围、快速选择、缓存输入和专用检查拆分的关系。
- 允许在必要且成本可接受时建议候选命令探测。
- 规定探测前展示命令组、总成本和可能副作用，获得用户确认后执行。
- 规定执行前后核对 Git 可见改动；发现差异后停止后续建议和写入，保留现场且不自动清理或恢复。
- 为规则补充最小技能契约验证。

## 验收标准

- [x] 初始化和审查都能指导动态扫描检查覆盖实际读取范围。
- [x] 范围扩大将拖慢复合检查时，规则建议拆分专用检查。
- [x] 静态证据充分时不建议候选命令探测。
- [x] 必要探测展示完整命令组、成本和副作用，并等待用户确认。
- [x] 探测发现 Git 可见改动时停止，保留现场，不自动清理或恢复。
- [x] 契约验证覆盖以上通用规则，且不包含运行边界检查特例。
