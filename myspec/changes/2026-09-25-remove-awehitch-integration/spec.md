# 移除 awehitch 集成

**状态：** ready-for-agent

## Problem Statement

用户已卸载 awehitch（ChatGPT 网页连接工具），但本仓库仍保存其项目级连接配置、补丁、测试、说明和流程引用，会继续提示安装或调用已经不存在的工具。

## Solution

从当前仓库文件中移除 awehitch 专属内容，并清理共用文件中的相关引用。Codex（代码代理）和 Claude Code（代码代理）本身及其无关技能保持可用。另两个仓库各自移除其项目级连接配置。

## User Stories

1. 作为使用者，我希望两个 Agent（代理）不再提供 awehitch 技能或连接，避免误调用。
2. 作为仓库维护者，我希望专属补丁、测试和说明消失，避免无效维护工作。
3. 作为仓库维护者，我希望共用开发流程只提供仍可用的审查方式，避免断开的审查入口。
4. 作为使用者，我希望检查能证明安装、配置和仓库没有当前 awehitch 残留。

## Implementation Decisions

- 删除专属连接配置、补丁、测试、说明、正式规格和三个只服务于 awehitch 的历史变更目录。
- 共用流程、策略、测试、检查配置及混合历史记录只移除 awehitch 相关内容。
- 开发流程保留现有本地代码审查入口以及“每票或整体审查”的时机选择。
- Git（版本管理）历史不改写；本次只清理当前版本文件。

## Testing Decisions

- 从工具命令、两个 Agent 的连接列表、三个项目配置和仓库文件检查残留。
- 使用仓库现有 Build and Verify（构建与验证）入口验证受影响的配置与规则。
- 检查从实际入口观察结果，不新增只重复实现细节的测试。

## Out of Scope

- 卸载 Codex、Claude Code 或其他无关技能和连接。
- 改写 Git 历史、清理远端账号里的历史聊天。

## Further Notes

cloudflared（隧道客户端）已由管理员卸载程序移除；本机用户目录的残留清理单独核对。
