# 01: 独立技能写入并查询列式数据

**What to build:** 使用独立安装形态的同一技能写入有类型记录，再按稳定逻辑表名查询；持久数据只有内部 Zstd 压缩的 Parquet，调用者不持有物理分片路径。

**Blocked by:** 门禁一完整内容展示后的明确确认；无前置实施票据。

**Status:** ready-for-agent

- [ ] write 与 query 两个公开操作满足当前变更规格，未增加第三类产品能力。
- [ ] 单技能运行闭包独立于源码仓库；两个代理客户端必需清单及仅此插件登记一致。
- [ ] DuckDB 单依赖可写入及查询结构化列；不把完整结果塞进不透明 JSON 或二进制字段。
- [ ] 数据集字段、类型与逻辑表名由调用方定义，通用技能不绑定 Sim2GSE；查询通过原生 fetchmany 分批消费，不强制物化完整结果列表。
- [ ] 失败写入不破坏已完成记录；同键替换、只读查询、边界输入和缺依赖有明确行为。
- [ ] 从独立技能真实入口获得红绿与冒烟证据；统一固定基线快速验证通过且选中检查非空。
- [ ] 独立审查无未解决阻塞；正式规格未提前修改。
