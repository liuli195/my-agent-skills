# 01: 按拉取请求场景选择构建与验证检查

**What to build:** 让同一份配置支持本地全部检查与拉取请求适用检查，命令输出能清楚说明选中、排除和跳过的结果；同步配置向导、审查说明和正式规格。来源：GitHub Issue #361。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 不带 `--pr` 的构建、快速验证和 `verify --full` 保持原行为。
- [ ] `build --pr` 排除 `pr: false` 的构建检查。
- [ ] `verify --pr --base <固定基线>` 依变更路径选择，配置变化只选拉取请求可执行检查。
- [ ] `verify --pr --full` 运行全部拉取请求可执行验证检查。
- [ ] 输出显示运行场景、已选和场景排除项；PR 场景空选择报告跳过，不能报告通过，也不生成空性能报告；本地空配置和有效缓存命中保持原行为。
- [ ] 非布尔 `pr` 配置在调度前失败；已发布命令入口测试覆盖以上结果和本地默认兼容性。
- [ ] 配置说明、初始化与审查入口、正式规格同步新语义。
