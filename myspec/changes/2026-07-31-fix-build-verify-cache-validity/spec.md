# 修复 Build and Verify 缓存有效性

**Status:** approved

## 来源

合并处理 GitHub Issues（GitHub 问题）#238、#239 和 #240。#237 属于 PR CI（拉取请求持续集成）汇总门禁，不在本变更范围内。

## 问题

Build and Verify（构建与验证）的 fast verify（快速验证）可能在三种情况下错误复用或遗漏验证：

1. `inputs`（缓存输入）中的 glob（通配符）被当作字面路径，匹配文件变化后旧缓存仍可命中；
2. `.build-and-verify/config.json`（配置文件）变化不参与检查选择，相关检查可能完全不运行；
3. cache key（缓存键）没有绑定固定 `runtime_version`（运行时版本），更新 runtime（运行时）后旧缓存仍可命中。

## 领域语言

- **Future Input（未来输入）**：当前没有匹配文件，但允许等待未来文件出现的 glob input（通配符输入）。
- **Glob Input（通配符输入）**：展开为稳定排序的 Git-visible file set（Git 可见文件集合）的缓存输入模式。

## 需求

### 1. 通配符缓存输入

- 显式 `inputs`（缓存输入）中的 `*`、`?` 和 `[` 模式必须展开为匹配文件，不得作为字面文件名处理。
- 通配符只匹配文件；字面目录继续表达目录型缓存输入。
- 展开结果必须稳定排序，并在缓存语义中保留原模式及匹配集合。
- 匹配文件的内容变化、新增或删除必须改变缓存键。
- 通配符属于文件集合，只包含 Git（版本管理）已跟踪文件和未忽略的未跟踪文件；Git 不可用或枚举失败时回退项目目录遍历。
- 字面单文件继续保留现有例外：即使被 Git 忽略，也参与缓存。
- Windows（Windows 系统）反斜杠和正斜杠模式必须产生一致结果。
- 绝对路径、包含 `..` 的越界路径，以及实际指向项目外部的匹配文件必须被拒绝。
- 无匹配通配符是合法 Future Input（未来输入）。初始化和配置审查必须提示“当前无匹配但合法”，验证运行时不得重复警告。
- 不存在的字面路径继续允许，但初始化和配置审查必须将其与 Future Input（未来输入）区分，并提示可能存在拼写错误。

### 2. 配置变化选择检查

- 当 `.build-and-verify/config.json` 是 changed file（变更文件）时，fast verify（快速验证）必须选择全部当前 `verify.checks`（验证检查项）。
- 输出必须只增加一条整体选择原因，不为每个检查重复输出。
- 配置结构错误必须在调度任何检查前失败。
- 配置变化只扩大选择范围，不强制绕过缓存。
- cache key（缓存键）必须继续包含当前配置内容：旧配置缓存不能命中，当前配置已经生成的缓存可以复用。
- 普通源码变化继续按现有 `paths`（受影响路径）选择检查。

### 3. 运行时版本绑定缓存

- fast verify（快速验证）和 full verify（完整验证）读写的缓存键必须包含固定 `runtime_version`（运行时版本）。
- 运行时版本只从现有固定版本来源读取，不增加文件摘要或其他后备身份。
- 运行时版本不存在时，快速验证和完整验证必须在运行检查或读写缓存前报错。
- `build`（构建检查）不使用缓存，运行时版本不存在时仍可运行。
- full verify（完整验证）写入的通过缓存必须使用当前运行时版本。
- `update-runtime`（更新运行时）不得删除旧缓存；版本变化后由新缓存键自然阻止旧缓存命中。

## 验证接缝

- 分支行为使用现有 runner integration seam（运行器集成接缝）、临时 Git 仓库和 fake runner（假执行器）进程内验证。
- 保留现有少量真实 verify（验证）命令入口覆盖，不新增重复端到端入口。
- 每张票据先留下因目标行为缺失而失败的检查，再用同一检查证明修复。
- canonical runtime（规范运行时）和仓库 runtime snapshot（运行时快照）必须保持一致。
- 每张票据完成后通过 Build and Verify（构建与验证）运行该票据的定向检查和真实用户入口冒烟；整体完成后运行风险匹配的完整验证及 fast verify（快速验证）。

## 范围外

- PR CI（拉取请求持续集成）跨平台汇总门禁 #237。
- 精确分析新旧配置差异以选择部分检查。
- 新增缓存清理策略、配置字段、依赖或文件摘要身份。
- 改变命令执行、并行、超时或性能预算行为。
