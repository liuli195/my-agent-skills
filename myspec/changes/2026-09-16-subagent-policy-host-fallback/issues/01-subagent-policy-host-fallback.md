# 01 — 子代理策略回退改为宿主默认承载同一角色

**What to build:** 宿主无法提供四个角色指定的模型或思考强度时，子代理策略不再放弃子代理，而是回退到宿主默认的子代理模型和思考强度，**承载同一个角色**；四个角色、职责与读写边界不因回退改变，回退在提示词和报告中显式声明。开发流程的参考文档同步指向该回退规则。技能正文保持宿主中立，不点名任何宿主。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 宿主无法提供指定模型或思考强度时，回退到宿主默认的子代理模型与思考强度，并承载同一角色。
- [ ] 四个角色及其职责、读写边界不因回退改变；不得因模型不可用而跳过角色，也不得改用主 Agent（代理）自行完成。
- [ ] 回退在委派提示词与结果报告中显式声明；既有的「不以其他配置冒充该角色」禁止性措辞保留。
- [ ] 技能正文保持宿主中立，不出现具体宿主名称；技能仍为单文件，顶层小节保持原样。
- [ ] 开发流程参考文档在提到固定模型与思考强度时，指向该技能的回退规则。
