# 04 — 同步 PR Flow 工具链身份

**What to build（构建内容）：** PR Flow（拉取请求流程）把本机 MySpec（自有规格）和 Build and Verify（构建与验证）的诊断身份写入 Git 可见工具链记录，并由专用受管 CI（持续集成）工作流以同一固定发布包或受信任源码包验证该身份。

**Blocked by（前置项）：** 01 — 统一工具生命周期与身份。

**Status（状态）：** ready-for-agent

- [ ] 新初始化的 PR Flow 创建工具链记录和唯一专用受管工作流，不修改已有业务工作流。
- [ ] 发布版固定包版本；源码版只接受官方来源、完整公开提交、固定包目录和固定包名，并在打包和隔离安装时禁用安装脚本。
- [ ] 诊断保持只读；完整流程和小改流程仅在身份变化时同步受管记录。
- [ ] 自动同步只接受原工作区和暂存区均干净的状态，只提交受管记录，并在提交后从新基线重新检查且有界重试。
- [ ] 未显式初始化升级的旧仓库保持旧行为并获得升级提示。
