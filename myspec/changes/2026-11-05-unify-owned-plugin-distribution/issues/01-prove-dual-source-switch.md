# 01：代表插件双版本实际切换与恢复

**状态：** ready-for-agent
**前置票据：** 无。
**门禁：** 门禁一待确认，本票不是执行授权。

## 交付行为

选一个包含脚本与资源的自有插件，经统一入口建立并验证该插件独立的开发及发布稳定云端对象，让 dot（云端助手）、本机 Codex（代码代理）新会话与 Claude（代码助手）实际切换、加载资源并恢复。只扩展此一个代表插件所需最小路径，先证明可行，不先实施全部九项。

## 验收

- [ ] 核对精确插件、两个对象身份、原安装和允许的修改；不能仅复用同一对象更新证据。
- [ ] 开发与发布为两个独立对象，完整包含技能、脚本、资源与依赖；选择代表插件及原因可复核。
- [ ] 经真实入口执行发布→开发→发布；三个目标端报告实际来源、版本、启用、技能发现、脚本和资源运行证据，无重复加载。
- [ ] 开发更新不覆盖原发布内容或稳定身份，原发布保持可恢复。
- [ ] 记录切换前状态；覆盖部分失败、资源发现失败和恢复路径，恢复失败明确报告各端真实状态。
- [ ] 记录打包耗时、大小和实验接口限制；关键安装切换入口不可用就停止并报告，阻塞其余票据，不擅改为网页上传。
- [ ] 预计单项超过十五分钟或 516 MB（兆字节）先停止申请批准；只在精确授权范围操作和清理测试数据。

## 公开测试接缝

统一入口请求→真实客户端安装管理→新会话实际加载及资源执行。命令/状态假体覆盖失败与恢复；真实三端证据不可由假体替代。

## 依赖与范围

仅代表插件及其必要清单/客户端适配；不执行正式发布，不扩展第三方，不将后续票据实现当作可行性验证。
