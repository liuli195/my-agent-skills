**门禁：** 门禁一待确认，且前置票据完成。

## 交付行为

维护者继续使用现有正式发布入口和持续集成，九项统一清单能生成正确市场投影及发布产物；两项软件包发布与自举保留。用户能够在完整九项范围核对开发/发布切换、更新及恢复结果。

## 验收

- [ ] 现有发布预检、输入变化及版本检查、市场投影生成仍可用，九项来源和产物一致。
- [ ] 两项软件包构建、既有发布流程及持续集成自举保留；验证不以真实正式发布作为手段。
- [ ] 复用既有构建验证入口完成风险匹配检查，不另建平行验证系统；名称无条件分支和三份清单一致性有证据。
- [ ] 逐项记录九项在三个目标端的来源、版本、技能和必要资源状态；覆盖开发→发布恢复及无重复加载。
- [ ] 汇总失败、恢复和未验证项，不将上传成功、同对象更新或内部假体结果当成跨对象实际加载证明。
- [ ] 修正规格与随包说明，说明旧会话刷新限制、第三方不在范围及准确操作边界。
- [ ] 测试数据按授权清理，保留用户原有数据；剩余物或无法恢复情况明确报告。
- [ ] 准备后续规格与交付门禁材料；不自行合并主干、推正式标签或正式发布。

## 公开测试接缝

现有正式发布命令预检及投影输出、软件包构建与自举入口、统一同步入口及三个目标端新会话实际加载。复用发布命令测试和软件包集成检查，采用针对性真实冒烟而非无依据全量回归。

## 失败与恢复

发布兼容失败阻塞交付；客户端失败按已记录状态尝试恢复并报告。预计耗时或空间超限先停止申请批准，不扩大权限或迁移范围。

## 实施期补充——完整盘点与清理（待门禁一复核）

- [ ] 完整列出云端受控目录的全部技能及实际发现入口，覆盖自有、第三方和开发依赖；逐项记录来源、依赖关系、替代路径、验证状态与可恢复性，不把范围缩减为九项。
- [ ] 开发完成后，先从新发现入口验证所需技能、脚本和资源，重新核对开发流程各依赖能唯一解析；没有替代或仍被需要的项明确列为清理阻塞并向用户说明，不能先删或静默保留后宣称全部完成。
- [ ] 按已确认的精确对象及删除影响清理旧受控链接、安装及确已不再需要的状态；保留必要命令程序、依赖和用户原有数据。永久删除须列出具体对象并取得所需确认。
- [ ] 完整盘点本机及云端本次测试文件、状态、安装、市场登记和远端测试对象，记录原状态及恢复结果；正式回归测试源码与临时产物分开列明，必要保留项及理由由父线程向用户明确。
- [ ] 仅在真实验收与审查不再需要临时证据后执行授权清理。清理后通过原生列表、文件／链接和状态检查证明测试残留已处理、原环境已恢复、必需依赖仍可用；再次初始化不重建旧受控发现入口。
- [ ] 留下逐项清理结果及未完成原因；无法恢复、无替代、缺少精确确认或新入口不可用均阻塞相应收尾，不能只清一个测试目录便报告全部完成。
