# 02：九项统一市场与安装更新

**状态：** ready-for-agent
**前置票据：** 01：代表插件双版本实际切换与恢复。
**门禁：** 原范围及新增初始化、完整盘点清理范围门禁一已确认；01可行性已由父线程交接验收。

## 交付行为

用户通过同一清单和同步入口检查、安装更新及切换九项，每项各有开发与发布稳定对象。dot（云端助手）与本机 Codex（代码代理）同步来源，本机 Claude（代码助手）跟随。两个命令工具初始化或更新不再误卸载统一市场中的有效安装。

## 验收

- [ ] 九项身份、来源、发布安装和依赖信息作为清单数据维护，两客户端市场及正式发布投影一致。
- [ ] 发布和同步处理逻辑没有按插件名称的条件分支；两个工具不再经同步技能名称特判，独立软件包命令仍可用。
- [ ] 核对并修复初始化、更新和清理中的旧市场假设；从两个工具真实生命周期入口验证统一市场版本保留。
- [ ] 九项可逐项核对两个稳定对象和版本，各端加载目标来源，无重复启用；不承诺旧会话即时刷新。
- [ ] 切换前记录来源和可恢复状态；部分端失败时报告、停止扩展并尝试恢复本次变更，不宣称三端原子成功。
- [ ] 同一市场的 Claude（代码助手）更新顺序执行；第三方及未请求的插件不受影响。
- [ ] 保留来源、版本与安全校验，两项软件包及自举继续工作；同步修正与九项统一相冲突的规格及技能说明。

## 公开测试接缝

统一同步入口与两个工具的初始化/更新入口，观察客户端安装列表、来源、启用及新会话资源运行。复用客户端命令/状态假体及软件包集成检查，完成适配后立即做相应端真实冒烟。

## 失败与恢复

旧安装迁移或任一端失败先停止；只恢复本次已记录的变更。未经精确授权不删除安装和用户数据，超时或空间阈值按规格处理。

## 实施期补充——初始化路径收敛（门禁一已确认）

- [ ] 更新现有 scripts/cloud_bootstrap.py（云端初始化脚本）及必要清单，使初始化与更新不再重建已经迁移并完成清理的旧受控技能发现路径；复用既有入口，不另建安装系统。
- [ ] 完整盘点现有受控技能，包含第三方与开发依赖，区分技能发现链接、源码、命令程序、依赖、缓存及状态。不能把初始化改动或清理范围默认为九项。
- [ ] 保留运行必需的两个命令程序及项目依赖；无替代发现入口的技能逐项报告，不能通过删除依赖或放宽唯一解析规则使检查通过。
- [ ] 从同一初始化／更新入口验证新路径及资源可用；重复初始化不得重建已清理的旧发现入口。失败先停止，不静默回到旧安装路径。

本节按用户确认实施；逐项验证替代之前保留旧发现路径，不以本票授权永久删除。

## 本票实施与待验收边界

两端共享市场与正式发布投影扩为九项；原发布登记继续维护九项身份、发布输入和共享依赖。两个命令工具的统一市场安装由同一同步流程管理，独立命令入口仍负责软件包与自举；初始化和更新不再将共享市场识别为必须卸载的旧来源。重复启用或资源无效在写入前阻止。

现有云端初始化入口支持逐技能原生发现映射及资源校验，验证后持久保存在原安装记录。后续初始化和更新不重建这些技能的旧链接；未替代项保留原行为，替代失效则明确失败并保留现有入口。本票没有在真实环境启用替代映射，也没有清理任何受控技能。

受控目录只读快照仍为47项：第三方作者27项、技能查找器1项、自有源码12项、两个命令包7项。10项开发流程依赖仍使用旧入口；这些项及其他第三方尚无替代发现证据，不能清理。完整逐项盘点记录由父线程协调，04须在真实发现与运行依赖验证后确认清理范围，并保留必要的迁移映射。

已取得的受控边界检查包括九项清单一致、工具初始化保留统一来源、独立软件包入口初始化／诊断／更新、原生路径资源校验及重复初始化；它们不是真实账号全部十八对象验收。九项实际对象与逐端加载、独立两轴审查及固定基线正式验证尚待完成，不推进03。
