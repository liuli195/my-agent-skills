# 02：九项统一市场与安装更新

**状态：** ready-for-agent
**前置票据：** 01：代表插件双版本实际切换与恢复。
**门禁：** 门禁一待确认，且 01 必须证明可行。

## 交付行为

用户通过同一清单和同步入口检查、安装更新及切换九项，每项各有开发与发布稳定对象。dot（云端助手）与本机 Codex（代码代理）同步来源，本机 Claude（代码助手）跟随。两个命令工具初始化或更新不再误卸载统一市场中的有效安装。

## 验收

- [ ] 九项身份、来源、发布安装和依赖信息作为清单数据维护，两客户端市场及正式发布投影一致。
- [ ] 发布和同步处理逻辑没有按插件名称的条件分支；两个工具不再经同步技能名称特判，独立软件包命令仍可用。
- [ ] 核对并修复初始化、更新和清理中的旧市场假设；从两个工具真实生命周期入口验证统一市场版本保留。
- [ ] 九项可逐项核对两个稳定对象和版本，各端加载目标来源，无重复启用；不承诺旧会话即时刷新。
- [ ] 切换前记录来源和可恢复状态；部分端失败时报告、停止扩展并尝试恢复本次变更，不宣称三端原子成功。
- [ ] 同一市场的 Claude（代码助手）更新顺序执行；第三方及未请求的插件不受影响。
- [ ] 保留来源、版本与安全校验，两项软件包及自举继续工作；同步修正与九项统一相冲突的规格及技能说明。

## 公开测试接缝

统一同步入口与两个工具的初始化/更新入口，观察客户端安装列表、来源、启用及新会话资源运行。复用客户端命令/状态假体及软件包集成检查，完成适配后立即做相应端真实冒烟。

## 失败与恢复

旧安装迁移或任一端失败先停止；只恢复本次已记录的变更。未经精确授权不删除安装和用户数据，超时或空间阈值按规格处理。
