# 08：通用数据能力支持当前运行目录

**状态：** ready-for-agent
**前置：** 无（可独立开始）
**授权：** 门禁一候选；未获实施确认。

调用者可用稳定目录或运行时显式目录接入同一能力，保留项目桥接和数据。

- [ ] 接入以实际加载包为准，不写死缓存、插件短名分支或项目业务。
- [ ] 来源切换验证新目录和必要资源，失败恢复；长进程更新后重新加载。
- [ ] Wow桥接保持tracked业务语义、数据不迁动；一次最小实际接入验收单列授权。

## 公开入口、阶段结果与依赖

**真实公开入口：** data-store技能的通用接入说明/随包公开脚本，以及调用者从稳定目录或显式运行目录加载相同公开读写能力；Wow现有项目桥接为实际调用者。

**开发阶段：** 无前置；用现有接入/桥接测试接缝和受控临时数据验证两种方式使用同一数据根和公开读写结果；无效实现目录明确失败、原绑定和数据保持。不会修改用户项目绑定或业务数据，不把链接检查通过当业务验收。

**发布后验收：** 依赖本票完成、新正式包、实际可执行目录或已核验任务资源，以及具体项目接入授权；对获准项目通过原桥接执行一次最小读写/读取验证，核对实际脚本来源及数据根。长进程结束或重启后再清理旧实现，不能留下指向已清任务目录的悬空绑定；失败恢复已记录入口。
