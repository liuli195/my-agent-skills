# 01 — 观测检查从尚未报告到终态

**What to build:** 让维护者在创建或更新 PR（拉取请求）后运行一次 `complete`（收尾），即可从检查尚未报告持续观测到等待或终态；`diagnose`（诊断）使用相同状态语义但不等待。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `空必需检查 + 空检查汇总` 被识别为检查尚未报告，并在 `complete` 中进入最多 60 秒的有界观测。
- [ ] 已报告的等待、通过、失败、取消和查询不可用状态拥有互斥分类及对应恢复动作。
- [ ] `complete` 和 `diagnose` 通过同一观测 Interface（接口）输出一致语义，未知状态不得进入审查或合并。
- [ ] 每轮刷新后复核源提交和目标提交，变化时当前观测失效并安全停止。
- [ ] 公开命令回归覆盖 `空 + 空 → pending → pass`、永久未报告、失败、取消、查询错误和提交变化。
