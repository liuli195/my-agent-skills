# 02 — 等待完整规则集收敛并同步完成合并

**What to build:** 让已通过必需检查的 PR（拉取请求）在规则集状态传播期间有界重试普通合并，并且只有确认合并成功后才报告完成和执行清理。

**Blocked by:** 01 — 观测检查从尚未报告到终态。

**Status:** ready-for-agent

- [ ] 普通合并仍是完整规则集的最终裁决，规则集拒绝后复用票据 01 的观测结果并在 60 秒内有界重试。
- [ ] 每次重试前复核源提交、目标提交和审查状态，任一变化时停止。
- [ ] 持续规则集阻塞保留 `ruleset_merge_blocking` 和原始平台错误。
- [ ] 删除 `--auto`（自动合并）恢复路径；只有普通合并成功后才输出 `merge_complete` 并清理。
- [ ] 公开命令回归覆盖规则集传播后成功、持续阻塞和提交变化；Pi `pr_flow` 工具真实冒烟覆盖创建后立即运行一次 `complete` 直至合并与清理。
