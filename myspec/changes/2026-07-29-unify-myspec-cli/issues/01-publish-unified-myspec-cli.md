# 01 — 发布可安装的统一 MySpec CLI

**What to build:** 将现有确定性规格操作与四个 Skill（技能）组织为单一可安装 npm（软件包管理器）发布包。用户安装后可通过稳定的 `myspec` CLI（命令行程序）运行全部既有业务命令，不再依赖 Skill（技能）内的脚本路径。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 当前源码能够生成可安装的 npm Tarball（npm 软件包），且包名、版本、命令入口和 Agent（代理）资源完整。
- [ ] 安装后的 `myspec` 保持全部既有业务子命令、参数、标准输出、标准错误和退出码行为。
- [ ] 启动器以全脚本方式定位唯一 Python（脚本语言）核心，并按已确认顺序选择 Python 3.12 或更高版本。
- [ ] 缺少合格 Python（脚本语言）时返回清晰的非零诊断，不自动安装或降级运行时。
- [ ] Python（脚本语言）核心保持零第三方运行时依赖，且不存在第二份兼容实现。
- [ ] 黑盒测试从打包后的安装命令验证行为，而不是调用内部函数或源码脚本路径。
