# Cloud Development Environment

## Purpose

通过统一入口重建和更新云端公共工具、技能与项目依赖，复用三个仓库的初始化能力。

## Requirements

### Requirement: 云端公共环境统一初始化

初始化  MUST 在公共安装前核对宿主提供的本次正式运行包身份、版本、完整文件与所需入口；旧自有克隆、全局npm和旧技能链接不再作为运行来源。公共依赖与其他第三方仍按配置准备。

#### Scenario: Observable outcome

- **WHEN** 首次或运行后重复初始化
- **THEN** 缺失或冲突来源在写入前拒绝；正常生成字节码不使未改变包失效，旧历史链接不重新导出。
### Requirement: 云端公共环境通用更新

通用更新  MUST 只对用户明确选择的公共来源或软件包解析新正式版本；官方插件更新归同步技能负责，初始化重新核对本次运行来源，不从旧状态回退。

#### Scenario: Observable outcome

- **WHEN** 执行update或明确latest选择
- **THEN** 未选择的公共版本保持；不能用旧自有npm或失效任务资源代替当前包。
### Requirement: 云端项目初始化复用既有能力
系统 MUST 支持技能、魔兽插件和量化仓库的项目初始化，Windows 调用既有准备入口，Linux 准备 Python 3.12 与声明的 Node 依赖，不将 Linux 准备声明为完整 Windows 游戏工具链。

#### Scenario: Git 链接工作树准备环境
- **WHEN** 用户通过 Git 创建工作树后显式调用初始化
- **THEN** 依赖及运行时声明一致且主环境有效时复用共享环境；缺失、过期或不一致时失败退出，不从链接工作树修改主环境
### Requirement: 云端初始化尊重操作边界
系统 MUST 将 Git 工作树生命周期与初始化显式衔接，安装失败返回非零状态；MCP、账号凭据迁移和未获准的外部目录清理不属于初始化职责。

#### Scenario: 已有内容和失效链接
- **WHEN** 初始化遇到冲突安装或失效的受管技能链接
- **THEN** 系统报告具体位置并停止成功状态，保留现场，外部创建和删除必须先获得相应授权
### Requirement: 云端初始化按项目声明连接数据存储

项目运行接入  MUST 由配置声明包、入口和稳定目标，不在通用实现按业务技能名分支。稳定绑定仅使用持久官方目录，既有来源冲突在项目准备前拒绝，业务数据保持；任务目录不得成为永久链接。

#### Scenario: Observable outcome

- **WHEN** 初始化声明项目绑定的项目
- **THEN** 通过当前包公开connect/check完成重复接入；不支持任务显式目录的项目停止，不能创建悬空临时链接。
