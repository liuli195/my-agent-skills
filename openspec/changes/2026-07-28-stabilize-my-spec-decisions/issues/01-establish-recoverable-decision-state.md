# 01 — 建立可恢复的待决定状态闭环

**What to build:** 用户能够通过确定性命令开始 my-spec 运行、一次保存完整待决定清单、逐项读取和决定，并在新进程中继续同一清单；不完整或越序操作会被明确拒绝。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] CLI（命令行接口）支持状态初始化、完整冲突列表写入、当前项读取、决定记录和状态报告。
- [ ] 首次展示前必须保存每个待决定项的正文、证据、原因和推荐答案；只有数量的输入失败。
- [ ] 状态转换、游标、决定值和原子写入由脚本校验。
- [ ] 真实 CLI 回归保存 13 项，决定第 1 项后由新进程稳定返回原清单第 2 项。
- [ ] 未决项存在时不能进入最终预览或应用阶段。
